개인정보 처리방침

Regna(레그나)는 iPhone에서 AI를 실행하는 개인용 에이전트 앱입니다. 이 안내는 Regna 앱과 제품 웹사이트에 적용됩니다. 서비스 연결 기능은 개발 빌드에서 검증 중이며, 설치한 빌드에 따라 제공 기능이 다를 수 있습니다.

대화·기억·문서와 AI 처리

대화, 저장한 기억과 앱에서 만든 문서는 iPhone의 앱 저장 공간에 저장합니다. 대화와 기억은 내려받은 AI 모델이 기기에서 처리합니다. Regna는 이 데이터를 개발자 서버나 외부 AI 서비스로 전송하지 않습니다. 앱의 대화·기억·문서 저장 폴더는 iCloud 기기 백업에서 제외하도록 설정합니다. 사용자가 공유 기능으로 내보내는 문서는 선택한 앱이나 수신처로 전달됩니다.

Google 계정과 연결 권한

Google 연결은 선택 사항입니다. Google 로그인에서 승인한 기본 프로필·이메일 주소와 계정 식별자를 사용해 연결한 계정을 구분합니다. Gmail, Google 캘린더와 Google Drive는 사용자가 해당 서비스를 연결할 때 각각 필요한 읽기 권한을 요청합니다. Gmail 승인만으로 캘린더나 Drive에 접근하지 않습니다. 아래 기능은 개발 빌드에 구현되어 있으며, 실제 계정 연동과 배포 검증을 진행 중입니다. Google 심사가 승인되었다는 뜻은 아닙니다.

Google 비밀번호는 Regna가 입력받거나 저장하지 않습니다. Google 로그인 SDK가 발급받은 인증 토큰을 해당 기기의 Keychain에 저장하고 필요한 경우 갱신합니다. 토큰은 대화, 모델 입력 또는 개발자 서버로 전달하지 않습니다.

Google에서 조회하는 정보와 목적

Gmail: 받은메일함 확인 요청에 답하기 위해 메일 식별자와 제목·보낸 사람·날짜 등의 메타데이터를 조회합니다. 현재는 첫 페이지의 최대 5개 메일을 표시하며, 메일 본문과 첨부파일은 읽지 않습니다. 메일 발송·삭제·읽음 상태 변경은 하지 않습니다.

Google 캘린더: 사용자가 지정한 기간의 일정을 확인하기 위해 본인 소유의 기본 캘린더에서 일정 식별자, 제목, 시작·종료 날짜와 시각, 시간대, 장소, 일정 상태를 조회합니다. 종일 일정과 반복 일정의 해당 기간 항목을 포함할 수 있습니다. 일정 생성·변경·삭제, 다른 사람의 캘린더 관리 기능은 제공하지 않습니다.

Google Drive: 파일을 찾기 위해 파일 식별자, 이름, 종류와 수정 시각을 조회합니다. 서비스 연결 화면에서는 목록을 조회하거나 이름으로 검색할 수 있고, 대화에서는 사용자가 알려 준 이름의 시작 부분으로 검색합니다. 파일 본문 검색·열람·다운로드·변경·공유·삭제는 하지 않습니다.

캘린더·Drive 조회는 한 페이지씩 가져오며, 현재 화면과 대화에는 기본 최대 20개 결과가 표시됩니다. 추가 페이지나 Google이 알린 불완전 검색 상태는 별도로 안내합니다. Google 연결 및 조회에는 인터넷이 필요합니다. iPhone에서 Google API로 직접 요청하며, 날짜 범위나 파일 이름 검색어와 인증 토큰이 해당 요청에 포함됩니다. Google은 로그인·인증과 요청한 데이터 제공을 위해 이를 처리합니다.

Google 조회 결과의 보관과 AI 처리

서비스 연결 화면에서만 조회한 Gmail·캘린더·Drive 결과는 그 화면의 임시 상태로 표시하며, 대화나 보관함에 자동 저장하지 않습니다. 해당 화면을 닫으면 표시 결과를 비웁니다. 대화에서 요청해 받은 결과와 출처·계정 표시는 해당 대화와 함께 iPhone의 앱 저장 공간에 저장합니다. 저장된 조회 결과는 이후 대화에서 기기 내 AI가 참고할 수 있습니다.

사용자가 답변을 기억이나 PDF로 따로 보관하면 각각 별도 항목으로 남습니다. 사용자가 직접 공유한 경우에만 선택한 앱이나 수신처로 사본을 전달합니다. Regna는 Google 조회 결과를 개발자 서버나 외부 AI 서비스로 보내지 않으며, 범용 AI 모델을 학습시키는 데 사용하지 않습니다.

Regna가 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다. Google 데이터를 광고, 판매 또는 사용자 프로파일링에 사용하지 않습니다. 개발자가 Google 조회 결과를 원격으로 열람하거나 개발자 서버에 보관하는 기능은 없습니다.

다른 서비스와 네트워크

사용자가 여는 네이버·쿠팡 등 서비스 화면은 해당 서비스와 직접 통신하며 로그인 세션은 앱의 WebKit 저장 공간에서 관리합니다. 네이버 앱 비밀번호 연결을 사용하는 경우, 성공적으로 확인한 자격 증명만 기기 전용 Keychain에 저장합니다. 각 서비스의 계정·주문·메일 등 원본 데이터는 해당 서비스에도 존재합니다. 온디바이스 AI라는 표현은 인터넷 서비스가 처리하는 데이터까지 기기 안에만 존재한다는 뜻은 아닙니다.

AI 모델 다운로드에는 모델 배포 서버와의 통신이 필요합니다. Regna에는 광고 SDK나 별도 방문·행동 분석 SDK를 넣지 않습니다.

보관, 삭제와 접근 철회

보관함에서 대화·기억·문서 항목을 밀어 삭제할 수 있습니다. 대화를 삭제하면 그 대화에 저장된 Gmail·캘린더·Drive 조회 결과도 삭제됩니다. 설정의 ‘대화와 기억 모두 삭제’로 두 항목을 한꺼번에 지울 수 있습니다. 따로 보관한 PDF 문서는 보관함에서 별도로 삭제해야 합니다. 저장한 내용은 사용자가 삭제할 때까지 기기에 보관합니다. 내려받은 모델은 설정의 ‘AI 모델’에서 삭제할 수 있습니다.

‘둘러보기 → 앱 및 서비스 연결 → Gmail’의 ‘이 iPhone에서 Google 로그아웃’을 누르면 이 기기에서 사용하는 Google 로그인 연결을 해제합니다. 같은 Google 로그인으로 연결한 Gmail·캘린더·Drive에 모두 적용됩니다. 기기 로그아웃은 Google 계정에 부여한 앱 접근 권한의 철회와 다릅니다. 접근 권한은 Google 계정의 서드 파티 연결 관리에서 Regna를 선택해 별도로 철회할 수 있습니다.

Google 로그아웃이나 접근 권한 철회는 이미 저장된 대화·기억·PDF를 자동으로 지우지 않습니다. 조회 결과까지 제거하려면 위 삭제 경로에서 해당 항목도 삭제해 주세요. 네이버 앱 비밀번호는 네이버 계정 보안 설정에서 폐기할 수 있습니다.

외부 서비스의 원본 메일·계정이나 사용자가 별도로 공유한 사본은 앱 내 삭제로 제거되지 않습니다. 지원 문의는 처리에 필요한 동안 보관하며, 삭제 요청을 받으면 법적 보존 의무가 없는 범위에서 삭제합니다.

웹사이트와 지원 문의

제품 웹사이트에는 가입 양식, 광고, 방문 분석 도구 또는 추적 쿠키가 없습니다. GitHub Pages가 웹 요청 과정에서 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고해 주세요.

지원 메일을 보내면 이메일 주소와 문의 내용을 이메일 서비스에서 처리합니다. 비밀번호, 인증번호 또는 메일함 전체를 보내지 마세요.
