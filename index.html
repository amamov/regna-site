궁금한 점을 확인하세요.

정말 무료인가요?

기본 온디바이스 AI는 레그나 구독료와 외부 AI API 결제 없이 사용하도록 개발합니다. 내 API 키로 OpenAI·Claude·Google Gemini·Regnax를 선택하면 제공자의 API 요금이 별도로 발생할 수 있습니다. 모델 다운로드에는 인터넷과 저장 공간이 필요하며 통신 요금도 별도입니다.

내 대화가 AI 서버로 전송되나요?

기본 온디바이스 모드에서는 보내지 않습니다. 외부 AI를 직접 선택하고 전송에 동의하면 요청에 포함된 대화·참고 기억과 웹 작업의 서비스 페이지 내용이 선택한 제공자로 직접 전송됩니다. 레그나 서버를 거치지 않으며, 제공자의 데이터 처리 정책이 적용됩니다.

인터넷 없이도 사용할 수 있나요?

모델을 내려받은 뒤에는 AI 대화를 기기에서 처리하도록 개발하고 있습니다. 모델 다운로드, 서비스 연결·조회, 외부 웹사이트와 선택형 외부 AI 사용에는 인터넷이 필요합니다. 온디바이스라는 말이 외부 서비스까지 모두 오프라인이라는 뜻은 아닙니다.

전화·예약·결제도 대신하나요?

현재 버전에는 구현되어 있지 않습니다. 첫 개발 버전은 로컬 대화와 대화·기억 보관함부터 시작합니다. 작업 실행 기능은 iOS에서 가능한 범위와 사용자 승인 방식을 검증한 뒤 안내합니다.

지금 설치할 수 있나요?

개발 중이며 기존 TestFlight 0.1.0 (2)와 최신 개발 기능의 범위가 다릅니다. 외부 API 키 기능은 아직 기존 TestFlight에 포함되지 않았습니다. 새 빌드의 실기기 검증과 배포가 끝나면 설치 링크와 지원 범위를 안내합니다.
