궁금한 점을 확인하세요.

정말 무료인가요?

구독료와 유료 AI API 비용 없이 제공할 계획입니다. AI 모델은 기기에서 실행합니다. 모델 다운로드에는 인터넷과 저장 공간이 필요하고, 통신 요금은 사용하는 요금제를 따릅니다.

내 대화가 AI 서버로 전송되나요?

현재 구현은 내려받은 모델로 기기에서 답변을 생성하며, 외부 AI 서버로 대화를 보내는 대체 처리 경로를 두지 않았습니다. 대화와 기억은 로컬에 저장합니다. 출시 전 실기기 검증을 거쳐 데이터 처리 범위를 안내합니다.

인터넷 없이도 사용할 수 있나요?

모델을 내려받은 뒤에는 AI 대화를 기기에서 처리하도록 개발하고 있습니다. 모델 다운로드와 외부 웹사이트 접속에는 인터넷이 필요합니다. 온디바이스라는 말이 외부 서비스까지 모두 오프라인이라는 뜻은 아닙니다.

전화·예약·결제도 대신하나요?

현재 버전에는 구현되어 있지 않습니다. 첫 개발 버전은 로컬 대화와 대화·기억 보관함부터 시작합니다. 작업 실행 기능은 iOS에서 가능한 범위와 사용자 승인 방식을 검증한 뒤 안내합니다.

지금 설치할 수 있나요?

아직 개발 중입니다. 실기기 테스트와 TestFlight 배포가 완료되면 설치 링크와 지원 기기를 공개합니다.
